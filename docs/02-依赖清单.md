## 三、版本锁定方法

- **后端**：第三方版本集中在 pom.xml `<properties>`（`mybatis-plus.version` / `springdoc.version` / `spring-ai.version`），Spring 官方件由 parent 锁定——review 后如需调整只改这三个属性；构建产物可复现。
- **前端**：`package-lock.json` 必须提交入库，CI/他人 clone 后用 `npm ci`（而非 `npm install`）保证与锁定版本完全一致。
- 升级原则：小版本随手升、大版本先查该清单中的"兼容性依据"列是否有 Boot 4 适配声明。
