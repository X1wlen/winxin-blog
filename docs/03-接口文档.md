# WinXin Blog 接口文档（契约篇）

> 版本：v0.1.0 · 状态：**仅定义契约，业务实现由开发者按此文档完成**
> 本文档是前后端并行开发的唯一契约：前端据此 mock 开发，后端据此实现；结构变更必须先改本文。

## 0. 全局约定

- Base URL：开发 `http://localhost:8080`（前端经 `VITE_API_BASE_URL` 注入）；生产同源 `/`。
- 业务路径统一前缀 `/api/v1`；健康检查 `/ping` 不带前缀（探活约定）。
- 请求/响应均为 `application/json; charset=UTF-8`（文件上传除外，用 `multipart/form-data`）。
- 所有响应（含错误）为统一结构：

```jsonc
// Result<T>
{ "code": 0, "message": "success", "data": { } }   // code=0 成功；非 0 失败，data 为 null

// 分页：data 固定为 PageResult<T>
{ "code": 0, "message": "success", "data": { "list": [], "total": 0, "page": 1, "pageSize": 10 } }
```

- HTTP 状态码如实设置：200 成功、400 参数错误、401 未登录、403 无权限、404 资源不存在、500 系统错误（全局异常处理器已统一实现）。
- 业务错误码分段：10000+ 通用 / 11000+ 认证 / 12000+ 文章 / 13000+ 用户 / 14000+ 评论 / 15000+ AI。
- 认证（预留）：除注册/登录外均要求请求头 `Authorization: Bearer <JWT>`；下表"权限"列仅作契约标注。
- 时间字段统一 ISO-8601：`2026-10-26T23:30:29+08:00`。
- 通用查询参数：`page`（默认 1）、`pageSize`（默认 10，最大 50）。

## 1. 认证模块 `/api/v1/auth`

### 1.1 注册 `POST /api/v1/auth/register`（匿名）

入参（body）：

| 字段 | 类型 | 必填 | 校验 | 说明 |
|---|---|---|---|---|
| username | string | 是 | 4~32，字母数字下划线 | 登录名，唯一 |
| password | string | 是 | 8~64 | 明文传输（HTTPS 保证安全），服务端 BCrypt 散列存储 |
| nickname | string | 否 | ≤32 | 为空则默认取 username |
| email | string | 否 | email 格式 | 唯一性校验 |

出参 `data`：`null`（注册成功直接返回，不自动登录——保持简单；如需注册即登录改为返回 1.3 的 token 结构）。

错误码：11001 用户名已存在、11002 邮箱已被使用。

### 1.2 登录 `POST /api/v1/auth/login`（匿名）

入参（body）：`username`、`password`（均必填）。

出参 `data`：

```jsonc
{ "token": "eyJhbGciOi...", "expiresIn": 86400,
  "user": { "id": "1932...", "username": "winxin", "nickname": "微信", "avatar": "https://..." } }
```

错误码：11003 用户名或密码错误、11004 账号已禁用。

### 1.3 登出 `POST /api/v1/auth/logout`（登录）

入参：无（身份来自 Token）。服务端将 Token 加入黑名单/删除（Redis，策略由你实现）。
出参 `data`：`null`。

## 2. 文章模块 `/api/v1/articles`

### 2.1 发布文章 `POST /api/v1/articles`（登录）

入参（body，DTO：ArticleCreateDTO）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| title | string | 是 | ≤128 |
| content | string | 是 | Markdown 正文 |
| categoryId | string | 否 | 分类 ID |
| tagIds | string[] | 否 | 标签 ID 列表 |
| summary | string | 否 | ≤512；为空时可由 AI 模块生成 |
| coverImage | string | 否 | 封面 URL |
| status | number | 否 | 0 草稿（默认）/ 1 直接发布 |

出参 `data`：`{ "id": "1932..." }`（新增资源的 ID）。

### 2.2 编辑文章 `PUT /api/v1/articles/{id}`（登录，仅作者）

入参：路径 `id` + body（同 2.1，字段可选更新）。出参 `data`：`null`。
错误码：12001 文章不存在、12002 无权编辑他人文章。

### 2.3 删除文章 `DELETE /api/v1/articles/{id}`（登录，仅作者/管理员）

出参 `data`：`null`（逻辑删除）。错误码：12001。

### 2.4 分页列表 `GET /api/v1/articles`（匿名可访问）

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| page / pageSize | number | 否 | 见全局约定 |
| keyword | string | 否 | 标题模糊搜索 |
| categoryId | string | 否 | 按分类过滤 |
| tagId | string | 否 | 按标签过滤 |
| onlyPublished | boolean | 否 | 默认 true；作者后台传 false 需登录 |

出参 `data.list` 元素（ArticleListVO，列表不含正文）：

```jsonc
{ "id": "1932...", "title": "...", "summary": "...", "coverImage": "...",
  "categoryId": "...", "categoryName": "后端", "tags": [ { "id": "...", "name": "Java" } ],
  "viewCount": 1024, "likeCount": 8, "publishedAt": "2026-10-26T20:00:00+08:00" }
```

### 2.5 文章详情 `GET /api/v1/articles/{id}`（匿名可访问）

出参 `data`（ArticleDetailVO）：2.4 的字段 + `content`、`author: { id, nickname, avatar }`、`createdAt`、`updatedAt`。
浏览计数在详情接口内异步 +1（实现方式由你决定）。错误码：12001。

## 3. 用户模块 `/api/v1/users`

### 3.1 修改资料 `PUT /api/v1/users/me`（登录）

入参（body，UserProfileUpdateDTO）：`nickname`（≤32）、`email`（可选）、`bio`（≤255）。
出参 `data`：更新后的完整资料 `UserVO { id, username, nickname, email, avatar, bio, createdAt }`。
错误码：13001 邮箱已被占用。

### 3.2 上传头像 `POST /api/v1/users/me/avatar`（登录，multipart/form-data）

入参：form 字段 `file`——jpg/png/webp，≤2MB。
出参 `data`：`{ "avatar": "https://.../avatar/xxx.png" }`（服务端存储路径策略由你实现，建议本地磁盘 + 静态映射或对象存储）。
错误码：13002 文件类型不支持、13003 文件超出大小限制。

## 4. 评论模块 `/api/v1/comments`

### 4.1 发表评论 / 回复 `POST /api/v1/comments`（登录）

> 回复与发表共用一个端点：`parentId = 0` 为根评论，非 0 为回复——REST 上评论是一级资源，"回复"只是带父 ID 的创建动作，避免出现 `/replies` 这类从属端点。

入参（body，CommentCreateDTO）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| articleId | string | 是 | 评论目标文章 |
| content | string | 是 | 1~1000 字 |
| parentId | string | 否 | 父评论 ID（回复时传） |
| replyToUserId | string | 否 | 被回复人（楼中楼展示"回复@xx"） |

出参 `data`：`{ "id": "1932..." }`。
错误码：14001 文章不存在或未开放评论、14002 父评论不存在。

### 4.2 评论列表 `GET /api/v1/articles/{articleId}/comments`（匿名可访问）

Query：`page`、`pageSize`（**根评论分页**，每条根评论内嵌全部回复——博客场景楼中楼数量有限，避免前端多次请求）。
出参 `data.list` 元素（CommentVO）：

```jsonc
{ "id": "...", "content": "...", "user": { "id": "...", "nickname": "...", "avatar": "..." },
  "replyToUser": { "id": "...", "nickname": "..." },
  "likeCount": 0, "createdAt": "...",
  "replies": [ /* 同结构的 CommentVO，仅一层 */ ] }
```

## 5. AI 模块 `/api/v1/ai`（契约先行，实现依赖 Spring AI 接入）

### 5.1 生成文章摘要 `POST /api/v1/ai/articles/{id}/summary`（登录，仅作者）

入参：路径 `id`；Query 可选 `maxWords`（默认 120）。
出参 `data`：`{ "summary": "……" }`（是否回填文章表由调用方决定）。
错误码：15001 文章不存在、15002 AI 服务不可用（映射 AI 调用超时/失败）。

### 5.2 写作助手 `POST /api/v1/ai/writing/assist`（登录）

入参（body）：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| mode | string | 是 | `polish` 润色 / `continue` 续写 / `title` 起标题 |
| content | string | 是 | 待处理文本，≤5000 |
| instruction | string | 否 | 补充指令（如"更口语化"） |

出参 `data`：`{ "result": "……" }`。
